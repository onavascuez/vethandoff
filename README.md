# VetHandoff

Prototipo de tablero de parte para hospitalización veterinaria: una fila por paciente, plan del día con toques, seguimiento de pruebas, tutor, presupuesto e histórico del ingreso.

**Demo:** https://onavascuez.github.io/vethandoff/

- Prototipo estático, sin backend. Los datos son de ejemplo y el estado se guarda solo en el navegador de quien lo abre.
- Pensado para móvil. Botón "Reiniciar demo" para volver al estado inicial.
- Nombre provisional.
